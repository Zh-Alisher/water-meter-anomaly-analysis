# Result tables

Все таблицы получены скриптом [`analysis.py`](../analysis.py) из исходных CSV тестового задания.

| Файл | Что содержит |
|---|---|
| `anomaly_summary.csv` | Краткая сводка: критерий, число приборов и число событий |
| `summary.csv` | Контрольные метрики расчёта |
| `01_negative_consumption.csv` | Все значимые отрицательные суточные расходы |
| `02_absolute_spikes.csv` | Все сутки с расходом > 1.5 м³ |
| `02_relative_spikes.csv` | Все относительные всплески ≥5× обычного уровня и >0.5 м³ |
| `02_spike_devices.csv` | Компактная сводка всплесков по приборам |
| `03_unrealistic_consumption.csv` | Все значения >20 м³/сутки |
| `04_leak_candidates.csv` | Приборы с непрерывным потреблением ≥90 суток |
| `05_zero_consumption_with_packets.csv` | Приборы с нулевым расходом ≥30 суток при передаче пакетов |
| `06_step_changes.csv` | Найденные устойчивые ступенчатые изменения |
| `07_magnet_days.csv` | Дни события «магнит» с 14-дневной базой и флагом падения ≥50% |
| `07_local_magnet_candidates.csv` | Приборы с наиболее выраженной локальной связью с «магнитом» |
| `08_chronic_high_consumption.csv` | Приборы с длительно высоким медианным расходом |
| `device_anomaly_flags.csv` | Витрина уровня прибора для Power BI |

## Проверка полноты

- отрицательный расход: 190 событий / 79 приборов;
- абсолютные всплески: 3 945 событий / 232 прибора;
- относительные всплески: 1 567 событий / 362 прибора;
- физически нереальный расход: 318 событий / 59 приборов;
- утечка: 307 приборов;
- нулевое потребление при пакетах: 694 прибора;
- ступенька: 121 прибор;
- для анализа «магнита»: 1 784 пригодных дня.

Исходные файлы работодателя в репозитории не публикуются. Для полного воспроизведения их нужно положить в папку [`data/`](../data/) и запустить `python analysis.py`.
